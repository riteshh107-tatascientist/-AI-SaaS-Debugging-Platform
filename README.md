## 📌 Overview

DebugAI Pro is a **full-stack SaaS-style platform** built using Streamlit that helps developers:

- Detect errors from logs automatically 🤖  
- Get instant solutions 🛠  
- Monitor user activity 📊  
- Manage users (ban/delete/restore) 👑  
- Generate reports 📄  

---

## ⚡ Features

### 🤖 AI Log Analyzer
- Extracts errors from logs
- Provides category + solution

### 💬 AI Assistant
- Ask any debugging question
- Instant response using rule-based AI

### 📊 Analytics Dashboard
- Login trends visualization
- Real-time activity tracking

### 👑 Admin Panel (Secure)
- Ban / Unban users
- Soft delete (Instagram-style)
- Restore deleted users
- Activity monitoring

### 🔐 Secure Admin System
- No hardcoded credentials
- Uses Streamlit Secrets
- Hidden admin access

### 📄 PDF Reports
- Generate debugging reports

### 🚨 Email Alerts
- Send alerts when errors detected
